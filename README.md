시험지 **문항별 답·풀이 뷰어**입니다. 브라우저에서 `index.html`만 열면 됩니다.

| 학년 | 과목 | 회분 | 시험 id |
|---|---|---|---|
| 1학년 | 물리학Ⅰ·Ⅱ | 21 | `e00`~`e20` |
| 2학년 | 고급물리학·물리학실험 | 24 | `s00`~`s23` |

## 저장소에 없는 것

학교 시험지 원본(문제 이미지·PDF)은 저작권이 학교에 있어 **포함하지 않았습니다.**
`pages/`, `pdf/`는 `.gitignore` 대상입니다.

시험지를 옆에 같이 보려면 둘 중 하나를 하세요.

- **뷰어에서 불러오기**: 상단 `시험지 PDF 불러오기` → 본인이 가진 기출 PDF 선택.
  pdf.js로 브라우저 안에서만 렌더링되어 IndexedDB에 저장되고, 서버로는 전송되지 않습니다.
  (파일명이 원본 그대로여야 어느 시험인지 자동으로 맞춰집니다.)
- **로컬 빌드**: `python build.py --src "원본 PDF 폴더"` (하위 폴더까지 파일명으로 찾음)
  → `pages/`(면별 JPG)와 `pdf/`(시험지+답지 합본)가 생깁니다. 이 둘은 공개 금지.

## 폴더

| 경로 | 내용 | 공개 |
|---|---|---|
| `index.html`, `data.js` | 뷰어와 풀이 데이터 | O |
| `figs/` | 답으로 그려야 하는 문항의 그래프·그림 | O |
| `solutions/` | 풀이만 담은 PDF (시험지 면 없음) | O |
| `pages/`, `pdf/` | 시험지 원본에서 생성 | **X** |

## 조작

- 왼쪽 위에서 학년 선택, 아래에서 시험 선택, 문항 카드를 누르면 오른쪽 시험지 면이 따라갑니다.
- `풀이 보기`로 풀이 접기/펴기, `j`/`k`로 다음/이전 문항.

## 주의

풀이 안에 조건이 서로 맞지 않거나 답이 둘 이상인 문항은 노란 메모로 표시해 두었습니다.

해석이 조금이라도 갈리는 문항(88개)은 `⚑ 검수` 배지와 사유를 달았습니다(`data.js`의 `flag`). 상단 `검수만`을 누르면 그 문항만 보이고, 왼쪽 목록의 `⚑n`은 시험별 개수입니다. 답지 PDF에도 같은 줄이 들어갑니다.
